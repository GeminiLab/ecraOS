The slab allocator.

SlabAllocator owns one cache per size class and selects the class from an allocation layout. It allocates no memory itself. When a class needs a slab, the allocator reports how many pages to supply, and the caller registers that memory and retries. The caller also serializes local operations and decides how to route a free, using SlabAllocator::owner_cpu to find the owning CPU. Remote frees reach a slab header without borrowing the allocator.

SlabCache offers the same machinery for a single caller-selected class.
