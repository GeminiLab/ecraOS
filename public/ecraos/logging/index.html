Kernel logging subsystem.

§Backend

The only backend is currently the platform-provided debug console. More backends and backend selection/configuration are planned.

§Usage

Use the log crate macros, such as log::info! and log::error!, to log messages. The kernel initializes the logging subsystem during boot.

The default maximum level is Debug and cannot be changed currently, so Trace messages are disabled. It’s planned to allow configuration of the maximum level in the future.

§Output format

[I   1.234567 0:2 ecraos::mem:123] message

The prefix contains the level, monotonic time in seconds with six fractional digits, logical CPU ID, task ID, target, and source line. Levels use E, W, I, D, and T for Error, Warn, Info, Debug, and Trace. The task ID is zero before scheduler initialization, and a missing source line is shown as zero. The target defaults to the module path and can be set by the log macro. The level and message use ANSI colors for their severity.
