Kernel image section information.

§Sections and symbols

This module provides information about sections in the kernel image that are used by the kernel itself during runtime. These sections do not exactly correspond to ELF sections. For example, the rodata section also covers the .init_array section. Currently there are 7 sections:

SectionDescription
textThe compiled kernel code.
rodataThe read-only data.
percpuThe initial data for per-CPU variables.
dataThe initialized writable global data.
rela_dynThe dynamic relocation entries.
gotThe global offset table.
bssThe zero-initialized global data.

This module uses symbols defined in the linker script (ecraos/link.ld) to locate these sections. Each section has three linker symbols marking its start, true end, and aligned end. The alignment is specified by the linker script, currently 64 KiB, and does not depend on the runtime page size.

§Relocation compatibility

This module resolves symbol addresses with PC-relative addressing. Queries return the current runtime ranges, which will change after relocation to a new address. Previously returned ranges and Section values do not update automatically.

§Usage inside the kernel crate

Initialization code uses this module to map the kernel image properly and clear the BSS section.
