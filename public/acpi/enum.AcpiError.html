LibUnimplemented

This is emitted to signal that the library does not support the requested behaviour. This should eventually never be emitted.

§

HostUnimplemented

This can be returned by the host (user of the library) to signal that required behaviour has not been implemented. This will cause the error to be propagated back to the host if an operation that requires that behaviour is performed.
