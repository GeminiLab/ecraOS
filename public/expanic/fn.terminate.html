The actual execution termination function.

expanic uses this function to terminate the execution. terminate is the default implementation that calls core::panic! with the supplied information in its message. Actual kernels should provide their own implementation with the same signature as the default and mark it with the #[terminate_handler] attribute.

With a replacement registered, a panic handler can forward ordinary Rust panics through this terminate interface. Without a replacement, the default implementation calls core::panic!, so invoking that fallback from a panic handler would start another panic.
