1//! Slab page layout and the operations performed on one slab.
2//!
3//! This module is responsible for the in-slab side of allocation. It initializes slabs, tracks
4//! locally available slots in bitmaps, and receives slots released by other CPUs.
5//!
6//! # Layout
7//!
8//! A slab occupies [`SlabLayout::slab_size`] bytes and starts at an address aligned to that size.
9//! Byte ranges below are offsets from the slab base, `C` is the size-class slot size, and `N` is
10//! [`SlabLayout::slot_count`].
11//!
12//! | Byte range | Contents |
13//! | --- | --- |
14//! | `0..32` | [`SlabPageHeader`] |
15//! | `32..64` | Reserved summary bitmap |
16//! | `64..64 + ceil(N / 64) * 8` | First-level bitmap stored as `u64` words |
17//! | End of first-level bitmap through `slot_offset` | Padding for object alignment |
18//! | `slot_offset..slab_size` | `N` object slots, each `C` bytes and aligned to `C` |
19//!
20//! [`SlabLayout::slot_offset`] is the smallest byte offset after the bitmap that is a multiple of
21//! `C`. There is no trailing padding because the slot's size and alignment is always a multiple of
22//! `C`.
23//!
24//! # Bitmaps
25//!
26//! Each bit in the first-level bitmap records whether its corresponding slot is locally available.
27//! A set bit means available. Bits beyond `N` remain clear. Allocation clears the bit of the slot
28//! it returns and local release sets it again, so a double-free triggers a debug assertion.
29//!
30//! A slab with more than 512 slots uses the summary bitmap as a second level. One summary bit marks
31//! a group of 512 slots, and a set bit means the group has a locally available slot.  Allocation
32//! locates a non-empty group through the summary and only scans the first-level bitmap of that
33//! group. For `N <= 512` the region stays reserved and unused, and the first-level bitmap is
34//! scanned directly. The region is a fixed 32 bytes region after the header, so the maximum number
35//! of slots supported in a slab is `32 * 8 * 512 = 131072` which is far more than `object_count`'s
36//! limit and any slab actually needs.
37//!
38//! Summary and first-level bitmaps are managed in 64-bit words.
39//!
40//! # Remote releases
41//!
42//! A slot released by another CPU is not recorded in the bitmap directly. The freeing CPU links it
43//! into [`SlabPageHeader::remote_free_head`] with a compare-and-exchange loop, and the owning cache
44//! later detaches whole batches and returns those slots to the bitmap. The header therefore carries
45//! two kinds of state: fields only the owner touches, and the atomic head that remote CPUs update.
46//! [`SlabPageHeader`] documents which is which.
47

64/// A slab page header.
65///
66/// The header stores slab ownership, intrusive-list links, local allocation state, and the atomic
67/// head of the remote-free list. It is the only part of a slab with a fixed Rust type. The bitmaps
68/// and object slots follow it in the same slab memory and are accessed through offsets.
69///
70/// # Concurrency
71///
72/// The slab's owner is the allocator or cache that registered it. Only owner operations may read or
73/// write `list_prev`, `list_next`, and `local_free_count`, and the caller must prevent two owner
74/// operations from running at once. Calls from tasks and from interrupt handlers on the same CPU
75/// count as concurrent here, and this type provides no lock for those fields.
76///
77/// A remote free may run at the same time as owner operations. It uses only `remote_free_head` of
78/// the header and the slot being released, and should not touch the owner-managed fields or the
79/// bitmaps. `owner_cpu`, `object_count`, and `size_class` never change while the slab is alive, so
80/// any CPU may read them safely.
81///
82/// Code that reaches slab memory through a raw pointer must borrow the individual fields it needs.
83/// Writing `&(*ptr).remote_free_head`, for example, borrows only the atomic field. Forming a
84/// reference to the whole header instead would claim that every other field stays unchanged for the
85/// reference's lifetime, which conflicts with concurrent remote frees.
86#[repr(C)]
87pub struct SlabPageHeader {
88    /// Head of the remotely freed slot list, or zero when no frees are pending.
89    ///
90    /// Updated concurrently by freeing CPUs and read by the owner. Each released slot stores the
91    /// previous head value in its first machine word, forming the list.
92    pub remote_free_head: AtomicUsize,
93    /// Previous slab in the slab list. Used by the owner to iterate the list.
94    pub list_prev: Option<NonNull<SlabPageHeader>>,
95    /// Next slab in the slab list. Used by the owner to iterate the list.
96    pub list_next: Option<NonNull<SlabPageHeader>>,
97    /// Immutable logical CPU id that owns the slab.
98    pub owner_cpu: u16,
99    /// Immutable slot capacity taken from the bound layout.
100    pub object_count: u16,
101    /// Number of slots available in the owner-managed bitmap, excluding pending remote frees.
102    pub local_free_count: u16,
103    /// Immutable object size class.
104    pub size_class: SizeClass,
105}

107/// Remote-free publication and reclamation for [`SlabPageHeader`].
108impl SlabPageHeader {
109    /// Publishes a freed slot to its owning slab.
110    ///
111    /// Runs on the freeing CPU without borrowing the owner. The slot's first word receives the
112    /// current list head, and a successful `compare_exchange_weak` with [`Ordering::Release`] makes
113    /// the slot and that link visible to the owner. After publication the slot belongs to the
114    /// owner, which may reuse it or release the slab memory at any time.
115    ///
116    /// # Safety
117    ///
118    /// `this` must identify a live initialized slab header. `obj_addr` must identify a live slot
119    /// in that slab, freed exactly once. The header and slot must stay live until publication.
120    /// No reference covering the complete header may overlap this operation.
121    pub unsafe fn remote_free(this: NonNull<Self>, obj_addr: VirtAddr) {
122        // SAFETY: This reference covers only `remote_free_head`, not the complete header.
123        // The owner accesses other fields individually through raw pointers.
124        let head = unsafe { &(*this.as_ptr()).remote_free_head };
125        let mut previous = head.load(Ordering::Relaxed);
126        loop {
127            // SAFETY: The caller owns the released slot until publication succeeds.
128            unsafe { obj_addr.as_mut_ptr_of::<usize>().write(previous) };
129            match head.compare_exchange_weak(
130                previous,
131                obj_addr.as_usize(),
132                Ordering::Release,
133                Ordering::Relaxed,
134            ) {
135                // Publication lets the owner immediately reuse the slot or reclaim slab memory.
136                Ok(_) => return,
137                Err(current) => previous = current,
138            }
139        }
140    }
141
142    /// Returns whether a live slab has pending remote frees.
143    ///
144    /// # Safety
145    ///
146    /// `this` must remain a live initialized header throughout the atomic load.
147    pub(crate) unsafe fn has_remote_frees(this: NonNull<Self>) -> bool {
148        // SAFETY: This reference covers only the live `remote_free_head` field. The owner
149        // accesses other fields individually through raw pointers.
150        unsafe { &(*this.as_ptr()).remote_free_head }.load(Ordering::Acquire) != 0
151    }
152
153    /// Detaches a published remote-free batch for the owner.
154    ///
155    /// Uses [`Ordering::Acquire`] so the caller can read the links written before publication.
156    ///
157    /// # Safety
158    ///
159    /// `this` must be live and the caller must prevent concurrent local allocations and frees.
160    unsafe fn detach_remote_frees(this: NonNull<Self>) -> usize {
161        // SAFETY: This reference covers only the live atomic field. The slab memory
162        // containing it remains allocated while the owner detaches the batch.
163        unsafe { &(*this.as_ptr()).remote_free_head }.swap(0, Ordering::Acquire)
164    }
165}

167/// A slab page used for object allocation.
168///
169/// The type covers only the header at the start of a slab. Its methods reach the bitmaps and object
170/// slots that follow it in the same memory, locating them through the bound [`SlabLayout`]. The
171/// caller owns the complete region and passes it in already aligned and writable, as described in
172/// the module documentation.
173#[repr(transparent)]
174pub(crate) struct SlabPage(SlabPageHeader);
175
176/// Local allocation and release operations for [`SlabPage`].
177impl SlabPage {
178    /// Initializes a slab page so that every slot is locally available.
179    ///
180    /// Writes the header from `layout`, clears the summary region, sets one first-level bit per
181    /// slot, and marks the groups that have a free slot. Bits beyond the slot count stay clear.
182    ///
183    /// # Safety
184    ///
185    /// The pointer must identify writable slab memory of the selected size, aligned to that size.
186    /// No previous live slots, references, or remote operations may access this memory.
187    pub(crate) unsafe fn init_at(this: NonNull<Self>, layout: &SlabLayout, owner_cpu: u16) {
188        assert!(core::mem::size_of::<SlabPageHeader>() == SLAB_HEADER_SIZE);
189        assert!(this.as_ptr().addr().is_multiple_of(layout.slab_size));
190        let header = SlabPageHeader {
191            remote_free_head: AtomicUsize::new(0),
192            list_prev: None,
193            list_next: None,
194            owner_cpu,
195            object_count: layout.slot_count as u16,
196            local_free_count: layout.slot_count as u16,
197            size_class: layout.size_class,
198        };
199        // SAFETY: The caller supplies the complete slab memory, including both bitmap regions,
200        // for exclusive use.
201        unsafe {
202            this.cast::<SlabPageHeader>().as_ptr().write(header);
203            this.cast::<u8>()
204                .add(SUMMARY_BITMAP_OFFSET)
205                .write_bytes(0, SUMMARY_BITMAP_SIZE);
206            for word in 0..layout.bitmap_words {
207                let remaining = layout.slot_count - word * BITS_PER_BITMAP_WORD;
208                Self::bitmap_word(this, word).write(
209                    u64::MAX >> (BITS_PER_BITMAP_WORD - remaining.min(BITS_PER_BITMAP_WORD)),
210                );
211            }
212            if layout.summary_words != 0 {
213                for group in 0..layout.slot_count.div_ceil(SUMMARY_GROUP_SLOT_COUNT) {
214                    let summary = Self::summary_word(this, group / BITS_PER_BITMAP_WORD);
215                    summary.write(summary.read() | (1u64 << (group % BITS_PER_BITMAP_WORD)));
216                }
217            }
218        }
219    }

221    /// Locates a first-level bitmap word.
222    ///
223    /// # Safety
224    ///
225    /// The slab memory must be valid and complete. The word must be below the layout's bitmap
226    /// length.
227    unsafe fn bitmap_word(this: NonNull<Self>, word: usize) -> *mut u64 {
228        // SAFETY: The caller provides complete slab memory and an in-bounds word index.
229        unsafe {
230            this.as_ptr()
231                .cast::<u8>()
232                .add(FIRST_LEVEL_BITMAP_OFFSET)
233                .cast::<u64>()
234                .add(word)
235        }
236    }

238    /// Locates a summary bitmap word.
239    ///
240    /// # Safety
241    ///
242    /// The slab memory must be valid and the word must be below the layout's active summary length.
243    unsafe fn summary_word(this: NonNull<Self>, word: usize) -> *mut u64 {
244        // SAFETY: The caller provides complete slab memory and an in-bounds summary index.
245        unsafe {
246            this.as_ptr()
247                .cast::<u8>()
248                .add(SUMMARY_BITMAP_OFFSET)
249                .cast::<u64>()
250                .add(word)
251        }
252    }

254    /// Returns the first slot address for slab memory with a matching slab layout.
255    fn slot_start(this: NonNull<Self>, layout: &SlabLayout) -> VirtAddr {
256        VirtAddr::from_mut_ptr_of(this.as_ptr()) + layout.slot_offset
257    }
258
259    /// Returns the address of a slot.
260    ///
261    /// Panics if `index` is outside the layout's slot capacity.
262    fn slot_addr(this: NonNull<Self>, layout: &SlabLayout, index: usize) -> VirtAddr {
263        assert!(index < layout.slot_count);
264        Self::slot_start(this, layout) + (index << layout.object_log2)
265    }

267    /// Locates the slab page containing a live object.
268    ///
269    /// Clears the low address bits, which identifies the base of a naturally aligned slab, rather
270    /// than scanning for a marker. The caller must name the slab's layout, because the slab
271    /// size in it determines how many bits to clear and nothing can be read before the base is
272    /// known.
273    ///
274    /// # Safety
275    ///
276    /// The address must identify a live slot in a slab with this exact slab layout.
277    pub(crate) unsafe fn from_object(address: VirtAddr, layout: &SlabLayout) -> NonNull<Self> {
278        let base = va!(address.as_usize() & layout.slab_mask);
279        let this = NonNull::new(base.as_mut_ptr_of::<Self>()).expect("live slab base is nonzero");
280        debug_assert!(address >= Self::slot_start(this, layout));
281        debug_assert!(address < base + layout.slab_size);
282        debug_assert!(
283            (address - Self::slot_start(this, layout)).is_multiple_of(1 << layout.object_log2)
284        );
285        this
286    }

288    /// Allocates one locally available slot.
289    ///
290    /// Returns `None` when the local count is zero. Otherwise clears and returns the first set
291    /// first-level bit. When the layout uses a summary bitmap, the search covers only the first
292    /// group with a set summary bit, and that bit is cleared once the group has no available slot.
293    ///
294    /// # Safety
295    ///
296    /// The slab memory must be valid and initialized with this slab layout. The caller must
297    /// prevent concurrent local allocations and frees.
298    pub(crate) unsafe fn local_alloc(this: NonNull<Self>, layout: &SlabLayout) -> Option<VirtAddr> {
299        let header = this.as_ptr().cast::<SlabPageHeader>();
300        // SAFETY: The caller serializes this individual local field.
301        if unsafe { (*header).local_free_count } == 0 {
302            return None;
303        }
304        let (first, end) = if layout.summary_words != 0 {
305            let group = (0..layout.summary_words)
306                .find_map(|word| {
307                    // SAFETY: The owner reads an initialized in-bounds summary word.
308                    let bits = unsafe { Self::summary_word(this, word).read() };
309                    (bits != 0)
310                        .then(|| word * BITS_PER_BITMAP_WORD + bits.trailing_zeros() as usize)
311                })
312                .expect("free count and summary must agree");
313            let first = group * BITMAP_WORDS_PER_SUMMARY_GROUP;
314            (
315                first,
316                (first + BITMAP_WORDS_PER_SUMMARY_GROUP).min(layout.bitmap_words),
317            )
318        } else {
319            (0, layout.bitmap_words)
320        };
321        for word in first..end {
322            // SAFETY: The selected bitmap interval is initialized and within the slab memory.
323            let bitmap = unsafe { Self::bitmap_word(this, word) };
324            let value = unsafe { bitmap.read() };
325            if value == 0 {
326                continue;
327            }
328            let bit = value.trailing_zeros() as usize;
329            let remaining = value & (value - 1);
330            // SAFETY: The owner serializes local count and bitmap updates.
331            unsafe {
332                bitmap.write(remaining);
333                (*header).local_free_count -= 1;
334                if layout.summary_words != 0
335                    && remaining == 0
336                    && (word + 1..end).all(|index| Self::bitmap_word(this, index).read() == 0)
337                {
338                    let group = word / BITMAP_WORDS_PER_SUMMARY_GROUP;
339                    let summary = Self::summary_word(this, group / BITS_PER_BITMAP_WORD);
340                    summary.write(summary.read() & !(1u64 << (group % BITS_PER_BITMAP_WORD)));
341                }
342            }
343            return Some(Self::slot_addr(
344                this,
345                layout,
346                word * BITS_PER_BITMAP_WORD + bit,
347            ));
348        }
349        unreachable!("free count and bitmap must agree")
350    }

352    /// Releases one slot to the local allocator.
353    ///
354    /// Sets the slot's bitmap bit, marks its summary group, and increments the local count. A slot
355    /// released twice trips a debug assertion.
356    ///
357    /// # Safety
358    ///
359    /// The slot must be live in slab memory with this slab layout. The slot must not have been
360    /// released. The caller must prevent concurrent local allocations and frees.
361    pub(crate) unsafe fn local_free(this: NonNull<Self>, layout: &SlabLayout, address: VirtAddr) {
362        let offset = address - Self::slot_start(this, layout);
363        debug_assert!(offset.is_multiple_of(1 << layout.object_log2));
364        let index = offset >> layout.object_log2;
365        debug_assert!(index < layout.slot_count);
366        // SAFETY: The caller identifies a live slot and serializes bitmap and local count access.
367        unsafe {
368            let bitmap = Self::bitmap_word(this, index / BITS_PER_BITMAP_WORD);
369            let mask = 1u64 << (index % BITS_PER_BITMAP_WORD);
370            debug_assert_eq!(bitmap.read() & mask, 0, "double free");
371            bitmap.write(bitmap.read() | mask);
372            if layout.summary_words != 0 {
373                let group = index / SUMMARY_GROUP_SLOT_COUNT;
374                let summary = Self::summary_word(this, group / BITS_PER_BITMAP_WORD);
375                summary.write(summary.read() | (1u64 << (group % BITS_PER_BITMAP_WORD)));
376            }
377            let header = this.as_ptr().cast::<SlabPageHeader>();
378            (*header).local_free_count += 1;
379        }
380    }

382    /// Drains one batch of remotely freed slots.
383    ///
384    /// The owner takes the whole published list with one atomic swap and walks it, returning each
385    /// slot to the bitmap. The swap uses [`Ordering::Acquire`], which makes the links the freeing
386    /// CPUs wrote visible. A release published after the swap stays on the head for a later drain.
387    ///
388    /// # Safety
389    ///
390    /// The slab memory must be initialized with this layout. The caller must prevent concurrent
391    /// local allocations and frees.
392    pub(crate) unsafe fn drain_remote_frees(this: NonNull<Self>, layout: &SlabLayout) {
393        // SAFETY: The caller supplies a live header and serializes the sole consumer.
394        let mut head = unsafe { SlabPageHeader::detach_remote_frees(this.cast()) };
395        while head != 0 {
396            let address = va!(head);
397            // SAFETY: The swap with Ordering::Acquire made this link visible to the sole consumer.
398            head = unsafe { address.as_ptr_of::<usize>().read() };
399            unsafe { Self::local_free(this, layout, address) };
400        }
401    }
