10    /// Early platform initialization.
11    ///
12    /// This method should be called immediately after the kernel entry runs,
13    /// and should perform the early platform initialization. This method will
14    /// be called only once, on the bootstrap processor.
15    ///
16    /// When this method is called, the following conditions are met:
17    ///
18    /// - The CPU is in its desired working state (for example, in long mode in
19    ///   the x86-64 architecture).
20    /// - Virtual memory and paging are enabled with an identity mapping.
21    /// - Allocation is not yet available.
22    /// - PerCPU data area for the BSP is available.
23    /// - Interrupts are disabled.
24    ///
25    /// This method should:
26    /// - Initialize the early debug console.
27    /// - Install the CPU's exception vector so synchronous exceptions can be handled.
28    /// - Initialize architecture timekeeping needed by subsequent early setup.
29    /// - Prepare other CPU-local state required before memory initialization and later architecture
30    ///   initialization hooks.
31    ///
32    /// It must leave the current CPU able to take and handle exceptions. It does not initialize an
33    /// interrupt controller or enable interrupt delivery.
34    ///
35    /// Architectures choose their own order. The recommended order is to initialize the debug
36    /// console, install the exception vector, then perform other early initialization. Interrupt
37    /// delivery must remain disabled.
38    pub fn init_early(arg: PlatformBootArg);
39
40    /// Initializes the global and BSP local interrupt controllers.
41    ///
42    /// The caller has completed platform discovery, mapped all reported MMIO regions, and
43    /// published the discovered controller configuration. Implementations retain shared controller
44    /// state needed by AP initialization.
45    ///
46    /// # Panics
47    ///
48    /// Panics if platform discovery did not publish the controller configuration.
49    pub fn init_later();
50
51    /// Installs the AP's exception path without enabling interrupt delivery.
52    pub fn init_early_ap();
53
54    /// Initializes the AP-local interrupt controller using BSP-published architecture state.
55    pub fn init_later_ap();
56}
