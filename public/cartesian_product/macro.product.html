cartesian_product

Macro product 

Source 
product!() { /* proc-macro */ }
Expand description

Expands literal dimensions into a Cartesian product array.

Each bracketed dimension is a comma-separated list of literals. The resulting array contains one tuple for every combination, in input order, with the last dimension varying fastest. A single dimension produces one-element tuples. With no dimensions or an empty dimension, the result is an empty array. A trailing comma after the final dimension is accepted.

An optional => callback!(...) suffix invokes a callback macro. Each callback argument that is exactly @ is replaced with the generated array. Other callback arguments are passed through unchanged.

§Examples

Generate a tuple array from two dimensions:

use cartesian_product::product;

let values: [(u8, u8); 4] = product!([1, 2], [3, 4]);
assert_eq!(values, [(1, 3), (1, 4), (2, 3), (2, 4)]);

Pass the generated array to a callback macro with @:

use cartesian_product::product;

macro_rules! capture {
    ($values:tt, $label:ident) => {
        ($values, stringify!($label))
    };
}

let captured = product!([1, 2] => capture!(@, pairs));
assert_eq!(captured, ([(1,), (2,)], "pairs"));
