Expand description

A generic page table entry.

All architecture-specific page table entry types implement this trait.

Flag validation is architecture-specific, and conversions can discard or imply flags that cannot be represented independently by the hardware.

Required Associated Types§

Source

type FlagError: Debug

The error type returned when the implementation rejects a flag combination.

Implementations can use a custom error type or MappingFlags. Implementations that never reject flags can use core::convert::Infallible.
