Struct LowerCoverage 

Source 
pub struct LowerCoverage<A: VirtAddr>(PhantomData<A>);
Expand description

Coverage of the lower virtual-address range.

Bits above the implemented virtual-address width must be zero. A is the semantic virtual address type used by the associated page table hierarchy metadata.
