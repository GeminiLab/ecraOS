pub struct AArch64PageTableMeta<const BITS: usize, const PAGE_OFFSET_BITS: usize, C: AArch64Coverage>(PhantomData<C>);
Available on AArch64 only.
Expand description

Metadata for an AArch64 page table hierarchy.

BITS selects a virtual-address width from 25 through 52 bits. PAGE_OFFSET_BITS selects the 4 KiB, 16 KiB, or 64 KiB granule, and C selects lower or upper coverage. The root may contain fewer entries than a full lower-level table.

These parameters describe geometry without checking CPU features or configuring translation control registers. The caller must pair the metadata with a compatible entry encoding and hardware regime. In particular, wider address formats can require additional architectural features.

const EACH_LEVEL_BITS: usize

The index width of a full page table at each hierarchy level.

This is the base-2 logarithm of the number of entries per page table. The root page table may use fewer bits when the address width requires it.

Source

const PAGE_INDEX_BITS: usize

The number of virtual-address bits used for the page index.

This subtracts the page offset from the full hierarchy’s address width.
