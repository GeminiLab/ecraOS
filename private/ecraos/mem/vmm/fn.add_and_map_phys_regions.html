Expand description

Adds or overwrites physical regions and updates their direct mappings.

Requires heap allocation, dynamically extensible PMM storage, and a page table managed by the buddy allocator. Each region must be nonempty. Its flags must contain only defined bits, exactly one role, and at least one of the READ, WRITE, and EXECUTE bits.

Also updates low-address identity mappings if identity mappings have not been removed. New NO_MAP regions remove existing mappings over their entire rounded pages.

Returns after completing local and required remote TLB invalidations.

§Overlap rules

  1. Before alignment, byte ranges must not overlap, as required by PhysMemoryRegions, unless overwrite_existing_if(new, old) returns true for each existing intersection. Regions are inserted in slice order, so existing regions include earlier entries from regions. Only the overlapping part of an old region is replaced. The callback receives the complete new region and the old region clipped to that intersection, with its original flags and description.
  2. After outward alignment to page boundaries, regions must satisfy the physical-region mapping rules. Compatible overlaps are allowed, but incompatible overlaps are rejected even if overwrite_existing_if permitted replacement of the original byte ranges.

§Calling this function

Do not call while holding a PMM table lock. The callback must not start another mapping operation, including through crate::mem::allocs::vmalloc.

This function itself disables preemption and local interrupts when necessary. The caller must NOT disable local interrupts when calling this function if the current CPU has been marked as IPI-ready, as it may cause deadlocks if another CPU is updating the page table.

Calling this function is expensive. Prefer passing several regions in one call.

§Panics

Panics if initialization or interrupt requirements are not met, a region is invalid or conflicts with existing physical regions or mappings, or mapping or TLB invalidation fails.

A panic does not undo physical region additions and page table changes that have been applied.
