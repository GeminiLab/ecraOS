Module panic

Kernel panic and bug handling.

§Usage

Use kpanic! for fatal kernel errors and bug! for unexpected internal errors. UnwrapOrBug adds methods to Option and Result that report a bug on failure. These interfaces are provided by expanic.

§Termination

This module provides the terminate function as the backend for expanic. It can also be used directly to terminate the kernel. terminate prints the diagnostic to the logger (or the debug console if the logging subsystem is not initialized), and then requests shutdown with ShutdownReason::Panicked.

Diagnostics include the reason, file, line, column, and message. Output is not reentrant and may deadlock if the logger or console is already locked.

With host-test, termination panics with the diagnostic instead of accessing kernel devices.
