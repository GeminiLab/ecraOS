Expand description

Storage primitives for a physical region collection.

Default must create empty storage. Clone preserves entries and uses the storage type’s normal allocation-failure behavior. Insertion preserves existing element order. A failed reservation or insertion must preserve the contents. Mutable access through the collection’s unsafe APIs requires callers to preserve its range and flag invariants.

fn reserve_regions( &mut self, total: usize, ) -> Result<(), PhysMemoryRegionsError>

Reserves capacity for at least the given total number of elements.

The count includes existing entries, rather than specifying additional entries. A count below the current length succeeds without shrinking storage. The contents are unchanged.

Source

fn insert_region( &mut self, index: usize, region: PhysMemoryRegion, ) -> Result<(), PhysMemoryRegionsError>

Inserts an element at a valid index without reordering other elements.

The index must not exceed the current length. A successful reservation for the new length guarantees that this operation succeeds without allocating.

fn retain<F>(&mut self, predicate: F)
where F: FnMut(&PhysMemoryRegion) -> bool,

Retains only the elements specified by the predicate.

In other words, remove all elements e for which f(&e) returns false. This method operates in place, visiting each element exactly once in the original order, and preserves the order of the retained elements.
