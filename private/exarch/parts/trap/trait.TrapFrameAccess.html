Expand description

The architecture-neutral accessors for a saved trap frame.

Kernel handlers use this trait rather than layout-specific fields so their control flow remains independent of x86 and RISC-V frame representations.

Required Methods§

Source

fn instruction_pointer(&self) -> VirtAddr

Returns the saved instruction pointer.

The returned address identifies the interrupted instruction or its architecture-adjusted continuation point.

Source

fn set_instruction_pointer(&mut self, instruction_pointer: VirtAddr)

Replaces the saved instruction pointer.

The new address becomes the continuation target when the architecture returns from the trap.

Source

fn is_user(&self) -> bool

Returns whether the trap interrupted user mode.

This describes the saved privilege state rather than the kernel’s current execution mode.
