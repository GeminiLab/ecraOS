fn find_path<'a>( &'a self, path: &str, ) -> Result<Option<DevTreeIndexNode<'a, 'i, 'dt>>, DevTreeError>

Finds a node by an absolute device-tree path.

Path components are matched against complete node names, including unit addresses. The root path / returns the root node. An absent node returns None. Empty components and the special components . and .. are rejected rather than normalized.

§Errors

Returns an error when the path is not absolute, contains invalid components, or encounters a malformed node name.
