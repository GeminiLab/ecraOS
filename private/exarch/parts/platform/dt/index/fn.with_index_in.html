Expand description

Runs a query while a caller-owned device-tree index buffer is borrowed.

The index and all nodes obtained from it are valid only for the duration of query. This lifetime boundary keeps the index from outliving the buffer that stores it.

The buffer may be unaligned. A buffer sized to the index layout plus alignment minus one bytes is sufficient regardless of its starting address. This function does not allocate.

§Errors

Returns an error when the supplied buffer cannot hold the index or when the query reports a device-tree parsing error.
