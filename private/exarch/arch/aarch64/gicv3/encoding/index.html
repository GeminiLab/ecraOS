Module encoding 

Source
Available on AArch64 only.
Expand description

Pure controller topology and physical interrupt encoding.

Host tests use these helpers without mapped registers or privileged instructions. GICv3 affinity, frame selection and software interrupt encoding.

These pure mechanisms do not own a logical CPU inventory or a reason mailbox.
