exspin

Module locks 

Source
Expand description

Reader-writer spin locks with kernel execution guards.

Uses the reader-count and writer-bit representation from spin’s reader-writer lock design. Successful acquisitions use acquire ordering and unlocking uses release ordering. There is no fairness guarantee, so a steady stream of readers may starve a writer.

Unlike the mutex, this lock retains its atomic state without the smp feature. Shared guards can coexist even on one CPU, so exclusive access must still check the active reader count.
