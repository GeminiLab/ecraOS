Expand description

A page iterator constructed from an address range.

Each item is the start address of a complete page in the range. Iteration proceeds in ascending address order and stops at the exclusive end, including when that end is one past the maximum address.

This trait is sealed. Only the iterator types provided by this crate can implement it.

Required Methods§

Source

fn new(range: Self::AddrRange, page_size: usize) -> Option<Self>

Creates an iterator over the pages in the given range.

The iterator owns its state and does not borrow the original range.

Returns None if the range is invalid, the page size is not a non-zero power of two, or a representable endpoint is not page-aligned.
