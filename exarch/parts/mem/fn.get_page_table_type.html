pub fn get_page_table_type<AL: PageAllocator, F: TlbFlusher<VirtAddr>>(
    mode: VirtAddrSpaceMode,
) -> OpaquePageTableType<VirtAddr>
Expand description

Gets the page-table descriptor for the specified mode, allocator, and TLB flusher.

The descriptor statically specializes its allocation, mutation, and destruction operations for AL and its pending cleanup for F. The caller chooses an allocator that can access and deallocate every table frame in the resulting hierarchies, and a TlbFlusher suitable for their hardware users. This function only selects the descriptor and does not allocate memory or perform invalidation.

§Panics

This function will and should panic if the specified mode is not in the list returned by virt_addr_space_modes, and not supported by the platform.
