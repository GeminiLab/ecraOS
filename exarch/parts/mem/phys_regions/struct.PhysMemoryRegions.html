Struct PhysMemoryRegions 

Source 
pub struct PhysMemoryRegions<S: PhysMemoryRegionsStorage>(S);
Expand description

A sorted collection of nonempty, nonoverlapping regions with one ownership role each.

Ranges retain byte precision. Adjacent regions are not merged. Every fallible mutation keeps the original contents on error. Callbacks are evaluated at most once per visited intersection and should not perform external mutations if their effects would need to be rolled back.

pub fn insert_overwrite_if<F>( &mut self, region: MemoryRegion, allow: F, ) -> Result<(), PhysMemoryRegionsError>
where F: FnMut(MemoryRegion) -> bool,

Overwrites a complete incoming range if every existing intersection is allowed.

Each predicate argument retains the old flags and description but is clipped to its exact intersection with the incoming range. The predicate is called once per intersection until one is rejected. Gaps are filled with the incoming region. Old portions outside the range retain their attributes.

§Errors

Returns OverwriteRejected when a predicate refuses any overlap, or an input or storage error before committing the replacement.

Source

pub fn transform_overlaps<F>( &mut self, range: PhysAddrRange, transform: F, ) -> Result<(), PhysMemoryRegionsError>
where F: FnMut(MemoryRegion) -> MemoryRegion,

Transforms only existing intersections without filling any gaps.

Each callback argument is an old region clipped to the requested range. The returned region must retain that exact range and contain valid flags. Portions outside the range are preserved.

§Errors

Invalid input, invalid callback results, and storage failures leave the contents unchanged.

pub fn overlay_with<F>( &mut self, region: MemoryRegion, transform: F, ) -> Result<(), PhysMemoryRegionsError>
where F: FnMut(MemoryRegion) -> MemoryRegion,

Transforms existing intersections and fills gaps from an incoming region atomically.

The callback has the same contract as transform_overlaps. Uncovered parts receive the incoming flags and description. This combines preserving old attributes with recording a complete reservation.

§Errors

Invalid input, invalid callback results, and storage failures leave the contents unchanged.
