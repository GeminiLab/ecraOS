Expand description

Returns the page-table descriptor for a RISC-V mode and caller-selected strategies.

The selected Sv39, Sv48, or Sv57 format captures AL for all operations that access, allocate, or deallocate table frames, and F for pending cleanup. See crate::mem::get_page_table_type for caller requirements.
