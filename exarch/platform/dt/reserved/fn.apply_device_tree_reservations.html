Applies all static FDT memory reservations to discovered RAM regions.

Reads the FDT reservation map and static reg properties below /reserved-memory. Intersections with usable RAM become reserved regions. A /reserved-memory child with no-map becomes a NO_MAP region so the early direct map omits it. Dynamic size requests are not allocated here because this function runs before the kernel allocator is available.

§Errors

Returns an error when the reservation map, structure block, reserved-memory properties, or region capacity is invalid.
