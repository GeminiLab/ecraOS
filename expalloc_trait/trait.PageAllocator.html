Expand description

A physical page allocator.

Implementations allocate physically contiguous, page-aligned frames and translate their physical addresses into virtual addresses through which the caller can access them. All frame counts use the page size reported by Self::page_size_shift.

Required Methods§

Source

fn page_size_shift() -> usize

Returns the base-2 logarithm of the allocator’s page size.

A page contains 1 << page_size_shift() bytes. The value must remain constant for the lifetime of every allocation made through this type.

Source

fn alloc_frames(page_count: usize) -> Option<PhysAddr>

Allocates a contiguous run of frames.

Returns the physical address of the first frame, or None when the requested run cannot be allocated. The returned address must be aligned to the allocator’s page size.

Source

fn dealloc_frames(addr: PhysAddr, page_count: usize)

Deallocates a contiguous run of frames.

addr and page_count must exactly match a previous allocation returned by this allocator.

Source

fn phys_to_virt(addr: PhysAddr) -> VirtAddr

Translates a physical address into an accessible virtual address.

Provided Methods§

Source

fn alloc_frame() -> Option<PhysAddr>

Allocates one frame.

By default, this delegates to Self::alloc_frames with a page count of one.

Source

fn alloc_frames_of_size(size_in_bytes: usize) -> Option<PhysAddr>

Allocates enough contiguous frames to cover a byte size.

By default, this delegates to Self::alloc_frames with a page count computed from the byte size.

Source

fn dealloc_frame(addr: PhysAddr)

Deallocates one frame.

By default, this delegates to Self::dealloc_frames with a page count of one.

Source

fn dealloc_frames_of_size(addr: PhysAddr, size_in_bytes: usize)

Deallocates the frames covering a byte size.

By default, this delegates to Self::dealloc_frames with a page count computed from the byte size. Therefore, size_in_bytes could actually be different from the actual number used when allocating frames. However, this is not promised to be the case for every allocator.
