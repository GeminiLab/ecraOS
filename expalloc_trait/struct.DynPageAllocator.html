Expand description

A function-pointer table for PageAllocator.

Each field stores one static associated method from the implementation selected by Self::new. Each new::<T> call fixes its implementation statically, while tables built from different implementations share this type and can be selected at runtime.

Source§

impl DynPageAllocator

Constructs function-pointer tables from static-trait implementations.

Each constructed table is independent of the implementation type that built it.

Source

pub fn new<T: PageAllocator>() -> Self

Creates a function-pointer table for a static-trait implementation.

T supplies the static associated methods stored in the returned fields. The table can then be passed around independently of T.
