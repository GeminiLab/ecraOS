#[semantic_type]
Expand description

Generates a configurable API for a semantic type represented by a primitive integer.

The field must be a primitive integer type, and the struct must have exactly one unnamed field. The macro always derives Debug, Copy, and Clone, adds #[repr(transparent)] when no repr attribute is supplied, and generates into_repr and From<Target> for Repr. It generates new and From<Repr> for Target by default. The no_from_repr option disables both construction paths.

The eq option derives PartialEq and Eq for the semantic type. ord derives those traits together with PartialOrd and Ord. The eq_repr option implements bidirectional equality with the representation. ord_repr implements bidirectional partial ordering and implies eq_repr. These groups are independent. The hash option derives Hash for the semantic type.

The lower_hex, upper_hex, and display options implement formatting traits. Each can take a string literal in parentheses to customize its format string. Without one, the formats are {:x}, {:X}, and {:}. The format string receives the representation as its first positional argument. Formatting flags supplied to the outer formatting call are not forwarded. Formatting reads through into_repr, which is available because generated types are Copy.

Do not derive a trait that the macro is configured to generate. See the crate documentation for examples and the complete input contract.
