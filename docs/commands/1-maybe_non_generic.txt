3. 第一个参数为单个 identifier，为函数副本的名字；
4. 第二个参数为泛型参数的替换规则；支持对 const 参数和类型参数的替换；不同替换规则之间以逗号分隔；

1. maybe_non_generic 的首个参数固定为单个 identifier，为函数副本的名字；

4. 常数泛型参数替换的格式为 `const(PARAM => arg_name: arg_type)`；

8. 新增一个特殊参数 `attr(xxx)`，对于每一个这个参数，都会在生成的函数上添加一个对应的attribute（#[xxx]），其中xxx可以是任何合法attribute；
