Expand description

The operations for one concrete multi-level page table type.

Mutation functions reconstruct a temporary concrete value while preserving its table frames. Destruction deallocates table frames through the concrete value’s destructor.

Creates a method table for a concrete single-root multi-level page table format.

M supplies the page table hierarchy geometry and must use A for virtual addresses. PTE supplies the concrete entry representation, and AL supplies table frame allocation, address translation, and destruction.

Both roots use the statically selected allocator for table frames and destruction.
