Runtime type-erased multi-level page table types.

OpaquePageTableType captures operations for concrete metadata, entry, and allocator types. OpaquePageTable combines those operations with an erased root to represent different multi-level page table formats in a single type. This permits runtime page table hierarchy format selection.
