pub struct OpaquePageTableType<A: VirtAddr> {
    methods: PageTableMethods<A>,
}
Expand description

A type-erased descriptor for a concrete multi-level page table type.

The descriptor stores operations specialized for one concrete multi-level page table format. It does not store a root page table and can create any number of OpaquePageTable values using that format.

The descriptor captures the allocator used for all table frame allocation and deallocation performed through those values.

Fields§

§methods: PageTableMethods<A>

The operations specialized for the selected concrete type.

The function pointers retain the concrete metadata, entry, and allocator types.

Available on AArch64 only.

Creates a descriptor for an AArch64 dual-root multi-level page table type.

ML and PTEL describe the lower-address root, while MU and PTEU describe the upper-address root. The two metadata types must use the same semantic virtual-address type and the corresponding lower and upper coverage policies.

pub unsafe fn new_pagetable_at( &self, root: OpaquePageTableRoot, ) -> OpaquePageTable<A>

Constructs an opaque multi-level page table from an existing hierarchy.

The value uses the concrete format captured by this descriptor and does not inspect or initialize the referenced root page tables. The returned value assumes responsibility for their hierarchies’ table-frame deallocation.

§Safety

The root variant must match the descriptor’s single-root or dual-root format. The hierarchies must match its concrete metadata and entry types, and its allocator must be able to access and deallocate their table frames. For a single root, the remaining requirements are those of PageTable::new_at. For dual roots, they are those of crate::pt::DualPageTable::new_at.

pub fn new_pagetable_alloc(&self) -> PagingResult<A, OpaquePageTable<A>>

Allocates and initializes a runtime type-erased multi-level page table.

The returned value uses this descriptor’s concrete format and stores the root addresses allocated by the descriptor’s captured allocator.
