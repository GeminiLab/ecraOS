Expand description

Metadata for a page table hierarchy format.

Implementations provide the virtual-address type, level widths, supported leaf levels. The derived constants use those values to describe table sizes and address-bit ranges.

Required Associated Constants§

Source

const LEVELS: usize

The number of levels in the page table hierarchy.

Levels are numbered from zero at the lowest page table. Implementations must provide a level count between one and five, inclusive.

Source

const PAGE_OFFSET_BITS: usize

The number of bits in an in-page offset of the smallest page.

This value is also the base-2 logarithm of Self::PAGE_SIZE.

Source

const LEVEL_BITS: [usize; Self::LEVELS] where [(); Self::LEVELS]: Sized

The number of bits handled by each level of the page table hierarchy.

LEVEL_BITS[0] is the width handled by the lowest page table, and LEVEL_BITS[LEVELS - 1] is the width handled by the root page table. For example, 32-bit x86 PAE page table hierarchies have [9, 9, 2], and RISC-V Sv39x4 page table hierarchies have [9, 9, 11].

Provided Associated Constants§

Source

const MAX_PAGE_LEVEL: usize = 0

The maximum hierarchy level whose page table entries can be leaf mappings.

The value must be less than Self::LEVELS. Level-zero page table entries can contain leaf mappings but never references to child page tables.

Source

const PAGE_SIZE: usize = _

The size of the smallest page in bytes.

The value is derived as 1 << PAGE_OFFSET_BITS.

Source

const LEVEL_BIT_RANGES: [(usize, usize); Self::LEVELS] = _ where [(); Self::LEVELS]: Sized

The virtual-address bit range handled by each page table level.

Each (start, end) pair is half-open: start is inclusive and end is exclusive. See Self::LEVEL_BITS for the level ordering.

Source

const LEVEL_TABLE_SIZE: [usize; Self::LEVELS] = _ where [(); Self::LEVELS]: Sized

The number of entries in a page table at each level.

Each value is 1 << LEVEL_BITS[level]. See Self::LEVEL_BITS for the level ordering.

Source

const VA_BITS: usize = _ where [(); Self::LEVELS]: Sized

The virtual-address width consumed by the page table hierarchy.

The value includes the page offset and the bit widths of every page table level.

Source

const LEVEL_PAGE_SIZE: [usize; Self::LEVELS] = _ where [(); Self::LEVELS]: Sized

The size of the virtual-address range covered by one entry at each page table level.

Level zero covers Self::PAGE_SIZE bytes. Each higher level multiplies the previous size by the number of entries in a child page table. At levels permitted by Self::MAX_PAGE_LEVEL, this is also the size of a leaf mapping.

Required Associated Types§

Source

type VirtAddr: VirtAddr + Debug

The semantic virtual-address type used by this page table hierarchy format.

It must support address arithmetic and hexadecimal formatting in addition to the common MemoryAddr operations.

Source

type Coverage: PageTableCoverage<VirtAddr = Self::VirtAddr>

The type-level virtual-address coverage policy for this page table hierarchy.

Canonical-address validation uses this policy.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
