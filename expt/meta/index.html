Page table hierarchy geometry and address-space metadata.

This module defines the metadata trait PageTableMeta, which describes:

  • The geometry of the page table hierarchy, including the page size, number of levels, and entries per page table.
  • The virtual-address type, constrained by the VirtAddr marker trait.
  • The virtual-address coverage policy, constrained by PageTableCoverage. A hierarchy can cover a lower-address range, an upper-address range, or both sign-extended ranges.

Each implementation of PageTableMeta describes a page table hierarchy format in a specific virtual address space of a specific architecture.
