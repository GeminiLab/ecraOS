Expand description

The local TLB flushing strategy for RISC-V 64.

Some(addr) uses address-specific SFENCE.VMA with ASID zero in a general-purpose register as rs2. It invalidates non-global leaf translations for that address and ASID zero. None uses SFENCE.VMA x0, x0, covering all addresses and ASIDs, including global translations.

Use this strategy only when address-specific invalidations affect ASID-zero, non-global translations. A global ancestor descriptor also makes a translation global. See TlbFlusher for synchronization requirements.
