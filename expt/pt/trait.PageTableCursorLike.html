Expand description

The common interface for cursors over page table hierarchies.

This trait is the common interface for single::PageTableCursor and dual::DualPageTableCursor. A cursor’s mutable borrow excludes other Rust mutations through the borrowed multi-level page table but does not synchronize hardware page walks.

Map and unmap round ranges outward to base-page boundaries. A successful return means the PTE mutations and any table-frame deallocations are complete, with TLB invalidations still pending. Errors retain earlier mutations, including any intermediate tables already installed and any table frames already deallocated. Operations are not transactional. See the crate-level documentation for access coordination requirements.

Cleanup remains pending until Self::clean_up processes it or Self::take_cleanup transfers it to the caller. Implementations also process any remaining cleanup automatically when the cursor leaves scope.

Required Associated Types§

Source

type VirtAddr: VirtAddr

The semantic virtual-address type accepted by this cursor.

It matches the virtual-address type of the borrowed multi-level page table.

Source

type Allocator: PageAllocator

The allocator used by this cursor.

Intermediate page tables are allocated through the borrowed multi-level page table’s allocator.

Source

type PageTable: PageTableLike

The multi-level page table type being mutated by this cursor.

The cursor borrows the multi-level page table mutably during mutation.

Required Methods§

Source

fn map( &mut self, vaddr: Self::VirtAddr, paddr: PhysAddr, size: usize, flags: MappingFlags, ) -> PagingResult<Self::VirtAddr>

Maps a virtual range to physical memory.

This operation changes page table entries while mapped data frames remain caller-managed. Replacing a child-table descriptor immediately deallocates its subtree’s table frames. See the trait-level contract for partial failure and cleanup.

Source

fn unmap( &mut self, vaddr: Self::VirtAddr, size: usize, ) -> PagingResult<Self::VirtAddr>

Removes mappings from a virtual address range.

This operation clears mappings but does not deallocate their data frames. Intermediate tables remain allocated. See the trait-level contract for partial failure and cleanup.

Source

fn clean_up(&mut self)

Processes pending invalidations using the selected TLB flushing strategy.

See PendingCleanup for synchronization requirements.

Source

unsafe fn take_cleanup(&mut self) -> PendingCleanup<Self::VirtAddr>

Transfers all pending cleanup out of the cursor without processing it.

§Safety

The caller must handle the returned cleanup properly after calling this function, and before any other operations on the cursor.

See PendingCleanup for synchronization requirements.

Dyn Compatibility§

This trait is dyn compatible.
