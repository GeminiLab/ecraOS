exslab

Module layout 

Source
Expand description

Slab layout records.

A layout record describes the offset of size of the slot region in the slab. It’s determined by the combination of slot size and slab size. Every supported combination is computed at compile time into LAYOUTS. A cache resolves one record when it is constructed and keeps using it.

It’s so designed that allocation code could be shared and only reads the record at runtime. Benchmarks show that this design is faster than a design that computes the record at runtime, and also faster than a design that uses the layout as a const generic parameter.
