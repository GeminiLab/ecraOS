Expand description

A slab page header.

The header stores slab ownership, intrusive-list links, local allocation state, and the atomic head of the remote-free list. It is the only part of a slab with a fixed Rust type. The bitmaps and object slots follow it in the same slab memory and are accessed through offsets.

§Concurrency

The slab’s owner is the allocator or cache that registered it. Only owner operations may read or write list_prev, list_next, and local_free_count, and the caller must prevent two owner operations from running at once. Calls from tasks and from interrupt handlers on the same CPU count as concurrent here, and this type provides no lock for those fields.

A remote free may run at the same time as owner operations. It uses only remote_free_head of the header and the slot being released, and should not touch the owner-managed fields or the bitmaps. owner_cpu, object_count, and size_class never change while the slab is alive, so any CPU may read them safely.

Code that reaches slab memory through a raw pointer must borrow the individual fields it needs. Writing &(*ptr).remote_free_head, for example, borrows only the atomic field. Forming a reference to the whole header instead would claim that every other field stays unchanged for the reference’s lifetime, which conflicts with concurrent remote frees.

Fields§

§remote_free_head: AtomicUsize

Head of the remotely freed slot list, or zero when no frees are pending.

Updated concurrently by freeing CPUs and read by the owner. Each released slot stores the previous head value in its first machine word, forming the list.

§list_prev: Option<NonNull<SlabPageHeader>>

Previous slab in the slab list. Used by the owner to iterate the list.

§list_next: Option<NonNull<SlabPageHeader>>

Next slab in the slab list. Used by the owner to iterate the list.

§owner_cpu: u16

Immutable logical CPU id that owns the slab.

§object_count: u16

Immutable slot capacity taken from the bound layout.

§local_free_count: u16

Number of slots available in the owner-managed bitmap, excluding pending remote frees.

§size_class: SizeClass

Immutable object size class.

pub unsafe fn remote_free(this: NonNull<Self>, obj_addr: VirtAddr)

Publishes a freed slot to its owning slab.

Runs on the freeing CPU without borrowing the owner. The slot’s first word receives the current list head, and a successful compare_exchange_weak with Ordering::Release makes the slot and that link visible to the owner. After publication the slot belongs to the owner, which may reuse it or release the slab memory at any time.

§Safety

this must identify a live initialized slab header. obj_addr must identify a live slot in that slab, freed exactly once. The header and slot must stay live until publication. No reference covering the complete header may overlap this operation.

unsafe fn detach_remote_frees(this: NonNull<Self>) -> usize

Detaches a published remote-free batch for the owner.

Uses Ordering::Acquire so the caller can read the links written before publication.

§Safety

this must be live and the caller must prevent concurrent local allocations and frees.
