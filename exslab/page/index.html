exslab

Source
Expand description

Slab page header, bitmap-based object tracking, and lock-free remote free.

Each slab page starts with a SlabPageHeader followed by the object array. Local (owner-CPU) operations use a bitmap under the slab lock. Remote (cross-CPU) frees use an atomic CAS stack – no lock required.
