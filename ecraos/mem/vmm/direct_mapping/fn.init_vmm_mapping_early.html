Expand description

Creates the initial page table and maps the discovered physical memory regions.

Each physical memory region is processed according to the physical-region mapping rules and mapped twice ( unless it’s ignored as per the rules): mapped to the direct mapping area and identity-mapped to the low-address space.

§Panics

Panics unless the layout is initialized and no page table has been created. Also panics if provided physical memory regions fail to meet the requirements, allocation fails, or a page table cannot be created.

§Safety

The caller must ensure that the regions are valid: regions must remain sorted and non-overlapping, every range must be nonempty, and all flags must remain valid. Valid flags contain only defined bits and exactly one role.
