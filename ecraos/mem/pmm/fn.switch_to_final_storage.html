pub(super) fn switch_to_final_storage() -> Result<(), PhysMemoryRegionsLockError>
Expand description

Switches the global physical memory regions table to dynamically extensible storage.

Call after heap initialization and direct-map activation, before removing identity mappings. The caller must exclude concurrent table updates and other storage switches until this call returns.

Does nothing if the table already uses final storage.

§Errors

Returns PhysMemoryRegionsLockError::NotInitialized if the table is unavailable, or PhysMemoryRegionsLockError::AlreadyLocked if either required lock cannot be acquired immediately.
