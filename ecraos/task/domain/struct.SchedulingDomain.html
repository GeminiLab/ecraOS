pub(super) fn add_cpu_deferred(&self, cpu: usize) -> Result<(), DomainError>

Adds one CPU without draining suspended tasks.

Domain-switch transactions use this two-phase form so membership can be rolled back before suspended ownership is published. The caller must invoke drain_suspended only after every related queue and membership update has committed.
