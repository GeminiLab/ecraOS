fn idle_pull(domain: &DomainRef, cpu_id: usize) -> Option<TaskRef>
Expand description

Pulls at most one tail task from another active queue in the same domain.

The snapshot is intentionally released before any Queue lock. Each source is revalidated while locked because a concurrent local domain switch may have made the snapshot stale.
