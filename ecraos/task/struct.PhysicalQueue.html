pub fn append_fifo( &mut self, domain: DomainId, entries: VecDeque<T>, ) -> Result<(), QueueStateError>

Appends a FIFO batch to the active queue of its domain.

The caller drains a source queue before invoking this operation, so extending the backing deque preserves the source ordering at the destination tail.

Source

pub fn is_empty(&self) -> bool

Returns whether the queue contains no runnable task.

The result is meaningful only while the caller retains the queue lock and has revalidated its attachment state.

Source

pub fn len(&self) -> usize

Returns the number of queued runnable tasks.

The result is an advisory snapshot used only while the caller retains the queue lock.

Source

pub fn try_reserve(&mut self, additional: usize) -> Result<(), QueueStateError>

Reserves queue capacity before a draining transaction begins.

A domain-switch transaction invokes this on every destination before the source enters Draining, which lets it fail without changing queue attachment state.

Source

Source

pub fn steal_tail_if( &mut self, domain: DomainId, eligible: impl FnOnce(&T) -> bool, ) -> Result<Option<T>, QueueStateError>

Pulls the newest same-domain entry only after its context handoff is complete.

The caller holds the source Queue lock while testing eligibility. An ineligible tail stays in its original position, preserving existing placement and FIFO behavior.

Source

pub fn take_matching( &mut self, domain: DomainId, matches: impl FnMut(&T) -> bool, ) -> Result<Option<T>, QueueStateError>

Removes the first matching entry from the active queue of its domain.

This narrow deterministic lookup supports the compatibility yield_to API. Normal scheduling always uses Self::pop and therefore remains FIFO.

Source

pub fn drain_fifo( &mut self, domain: DomainId, ) -> Result<VecDeque<T>, QueueStateError>
