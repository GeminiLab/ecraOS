Terminates execution with a reason, source location, and message.

The default implementation calls core::panic! with the supplied information in its message. Whether this unwinds or aborts depends on the application’s panic strategy and panic handler.

To change this behavior, apply #[expanic::terminate_handler] to a function with the same signature. A kernel can forward ordinary Rust panics to that function from its panic handler. Calling the default implementation from a panic handler would cause another panic.
