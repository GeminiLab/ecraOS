Crate expanic 

Source
Expand description

Kernel panics and bug reports.

Use kpanic! to report a fatal kernel error, or bug! to report an unexpected internal error. Both call terminate with a formatted message and the module path, file, line, and column of the macro call. UnwrapOrBug adds methods to Option and Result that report missing values and errors as bugs.

By default, terminate calls core::panic! with the supplied information. An application can replace this function by applying #[expanic::terminate_handler] to a function with the same signature. A kernel can use its replacement to log the error and shut down.

This crate is no_std and requires nightly Rust for extern_item_impls. It does not define a panic handler or provide platform shutdown code.
