Expand description

Methods that unwrap an Option or Result and report failures as bugs.

Returns the value in Some or Ok. On None or Err, calls terminate with TerminateReason::Bug, an error message, and the file, line, and column of the method call. The caller’s module path is unavailable for these method calls.

use expanic::UnwrapOrBug;

assert_eq!(Some(42).unwrap_or_bug(), 42);
assert_eq!(Ok::<_, &str>(42).expect_or_bug("initialization failed"), 42);

Required Associated Types§

type Output

The value returned on success.

This is T for both Option<T> and Result<T, E>.

Source

type Err: Debug

The error included in the bug report.

This is E for Result<T, E>, or () for Option<T>. It is formatted using Debug.

Provided Methods§

Source

fn unwrap_or_bug(self) -> Self::Output

Returns the value in Some or Ok, or reports a bug and terminates execution.

On None or Err, calls terminate with TerminateReason::Bug and the method call’s source location. The message includes the error formatted using Debug, or () for None.

Source

fn expect_or_bug(self, msg: &str) -> Self::Output

Returns the value in Some or Ok, or reports a bug with the supplied message.

On None or Err, terminates execution as Self::unwrap_or_bug does, adding msg before the error in the report. Includes the source location of this method call.

Dyn Compatibility§

This trait is not dyn compatible.
